   The old text was hand-wavy ("whichever … was iterated last"). The new text states the concrete values per row and adds the **within-row contradiction** with the headline `Score` column (`0.0` vs `1.0` on the same row) — the smoking-gun evidence noted in `per-finding/F30.1.md`.

3. **`extra`: "two `@task`s … both rows show the same collision"** → **"two `@task`s with the scorer list **reversed** between them, so the two grid rows display contradictory `accuracy` values for identical underlying scores."**

Task `b` now uses `[beta, alpha]`, so the grid renders `1.0` and `0.0` on adjacent rows for identical data, making the collision visually self-evident. Description updated to match.
