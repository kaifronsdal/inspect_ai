2. **where_to_look** — "note the position of every `system` row" → "row **1** (`SYSTEM`). Compare against row **4** (`USER`), which renders a `Metadata` section. New text gives row numbers that match the rendered `1…5` labels and adds the JSON-tab step so the user can verify the metadata is in the log.

Row count verified: DOM row labels = `[1,2,3,4,5]`.
4. **expected** — old text demanded "each system message renders at its actual position", which contradicts the by-design collapse. New text asks for the merged row to **preserve and display** the source metadata (matching every other role), *or* render in place only when system messages are non-contiguous.
5. **extra** — added explicit "**Note:** collapsing … is *intentional* … the bug is the **side-effect**" so reviewers don't dismiss the finding as "they meant to do that".
