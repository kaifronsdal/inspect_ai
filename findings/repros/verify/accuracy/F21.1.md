## Inaccuracies fixed

1. **Banner hidden in collapsed sub-agent span** — `solver=chain(banner(), generate())` rendered as two collapsed `SUB-AGENT: BANNER` / `SUB-AGENT: GENERATE` rows; the InfoEvent was invisible at the Default filter. → Replaced with a single `repro_solver()` that calls `emit_bug_banner(DESC)` inline then `await generate(state)`. Banner now appears as the first expanded `INFO: BUG-REPRO` panel.
2. **Wrong column header name** — `where_to_look` said "click the **passfail_scorer** column header". There is no such header; the column is labelled **Score** (`passfail_scorer` only appears in the log summary's SCORER field). → "click the **Score** column header (rightmost) once to sort ascending."
3. **Missing back-navigation** — the banner lives inside a sample dialog, but the bug is in the top-level grid. A user reading the banner had no cue to leave the sample. → Prefixed `where_to_look` with "Close this sample → **Samples** tab (the log-level grid) → …".

Minor polish: added the badge-colour gradient (`green → red → red → orange` vs expected `green → orange → red → red`) to `observed`/`expected` so the wrongness is obvious without decoding the letter codes.
