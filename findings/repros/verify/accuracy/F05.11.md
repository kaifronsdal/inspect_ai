## Inaccuracies fixed

1. **chain() hid the banner** — `solver=chain(banner(), generate())` wrapped the InfoEvent in a collapsed `SUB-AGENT: BANNER` row at Default filter, so the bug description was invisible. → Replaced with a single `repro_solver()` that calls `emit_bug_banner(DESC)` inline then `await generate(state)`. Banner now renders as an expanded `INFO: BUG-REPRO` panel at the top under Default.
2. **"expand the Sample Init event (first event)"** → **"set the Events filter (top right) to Debug → expand the Init span (first row) → look at the Sample panel's SAMPLE sub-tab"** — the panel is hidden under the Default filter (must switch to Debug); the on-screen label is **`INIT`** not "Sample Init"; and the target content is the nested **Sample** panel's **SAMPLE** sub-tab, not the Init row itself.
3. **"shows Files / Setup / Target / Metadata"** → **"shows section headings Files / Setup / Target (and a separate Metadata sub-tab)"** — Metadata is a sub-tab pill alongside SAMPLE, not a section heading in the same column as Files/Setup/Target.
4. **"no row for …"** → **"no section for …"** — the panel uses titled sections (`EventSection`), not rows.
5. **Missing minor-impact note** — added to `extra`: `**Note:** impact is minor — sample.id is already displayed in the dialog header (top right) and in the ID column of the summary row above the tabs, so only sample.sandbox is genuinely missing, and per-sample sandbox overrides are uncommon.` Also dropped the `ID row` clause from `expected` since adding it would be redundant.

Additionally clarified the JSON-tab verification path to `JSON tab → events → the sample_init event → sample.sandbox`.
